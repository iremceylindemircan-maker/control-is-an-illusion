# CONTROL IS AN ILLUSION

### An Interactive Media Project

**Premises:** Agency × Possibility

## About the Project

Control Is an Illusion is an interactive experience that explores the relationship between personal agency and the limits imposed by a system.

At first, participants can add, move and resize geometric shapes. However, every action has consequences. As participants continue interacting, the system gradually locks available tools and reduces their freedom.

The project asks a simple question:

**If every action changes what you are allowed to do next, how much control do you really have?**

## The Two Premises

### 1. Agency

The participant is not a spectator. Their actions directly change the system and its visual environment.

### 2. Possibility

The system determines which actions remain available. As the participant interacts, some possibilities disappear.

The two premises work together: participants exercise agency, but their actions also transform the possibilities available to them.

## How to Use

1. Open the published website.
2. Use the Add Shape button to create a shape.
3. Select a shape by clicking on it.
4. Use the arrow buttons to move the selected shape.
5. Use the plus and minus buttons to resize it.
6. Observe the freedom meter and the locked tools.
7. Use Reset Experiment to start again.

Keyboard alternatives:
- A: Add a shape
- Arrow keys: Move the selected shape
- + / -: Resize the selected shape
